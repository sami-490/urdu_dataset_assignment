# Audio Directory (wavs/)

Place all 500 recorded `.wav` files in this directory.

### Requirements:
- **Naming format:** Zero-padded 6 digits (`urdu_000001.wav` to `urdu_000500.wav`)
- **Sample Rate:** 44.1 kHz or 48 kHz
- **Bit Depth:** 16-bit PCM
- **Channels:** Mono (1 channel)
- **Duration:** 3 to 7 seconds per file
- **Silence:** 50ms to 100ms leading & trailing silences
